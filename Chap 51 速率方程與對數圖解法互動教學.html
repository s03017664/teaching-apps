完整數學推導過程 (Mathematical Derivation)

點解可以將一條複雜嘅曲線方程變做簡單嘅直線方程？以下係逐步推導：

步驟 一 (Step 1) 基本速率方程

寫出反應物 A 的速率方程 (Rate Equation)：

Rate = k · [A]n
步驟 二 (Step 2) 取對數 (Taking log₁₀)

喺等式兩邊同時取以 10 為底嘅對數 ($\log_{10}$)：

log10(Rate) = log10( k · [A]n )
步驟 三 (Step 3) 應用對數法則 (Log Law for Multiplication)

利用對數乘法法則：$\log(ab) = \log(a) + \log(b)$ 將右邊拆開：

log10(Rate) = log10(k) + log10( [A]n )
步驟 四 (Step 4) 應用次方法則 (Power Law)

利用對數次方法則：$\log(x^n) = n \cdot \log(x)$ 將指數 $n$ 拉到前面：

log10(Rate) = log10(k) + n · log10([A])
步驟 五 (Step 5) 對比直線方程 y = mx + c

重新排列項目，對比標準直線方程 $y = mx + c$：

y = m · x + c
log10(Rate) = n · log10([A]) + log10(k)
如何求得反應級數 (Order n)？ 計算對數圖直線嘅**斜率 (Slope m)**，斜率的數值直接等於反應級數 $n$：
n = Slope = Δy / Δx
如何求得速率常數 (Rate Constant k)？ 找出直線嘅 **y-截距 (Intercept c)**，取反對數 (10c) 即可求出 $k$：
k = 10y-intercept
