❓ 30 秒完成一次性連線設定

  1. 1
    登入免費 GitHub 帳號（已有帳號直接跳第 2 步）。
  2. 2
    點擊下方直達按鈕開啟授權碼頁面（已自動勾選 repo 權限）：
    🔑 直達 GitHub 生成授權碼 ↗
  3. 3

  4. 4

📱 電腦與手機實時同步＆安裝成 App

💡 實時同步原理：所有教材名稱、資料夾及上傳時間都儲存在你 GitHub 倉庫內的 catalog.json。只要電腦與手機連線至同一個 GitHub 帳號和倉庫，電腦上載後，手機會在 15 秒內自動出現新網址（按「🔄 立即同步」即時更新）。
  1. 1
    把本工具放到雲端變成專屬網址：用本工具將 html_to_url_publisher.html 自己上載一次（網址代號填 publisher），就能在手機瀏覽器直接打開你的專屬控制台。
  2. 2
    一鍵加至主畫面（像原生 App 一樣用）：在 Android Chrome 按右上角 ⋮ → 「加至主畫面」（iPad Safari 按分享 → 「加入主畫面」），桌面就會出現圖示並全螢幕開啟。
  3. 3
    免在手機重打授權碼：按下方按鈕複製你的「跨裝置同步碼」，傳給自己（例如 WhatsApp 傳給自己），再到手機版按「📲 貼上跨裝置同步碼」即可一秒完成連線！
✅ 專屬手機版網址已發布！用手機掃描下方 QR Code 即可開啟
